# How TikTok Recommends Content

**Source:** TikTok Support (official documentation)

**URL:** [support.tiktok.com](https://support.tiktok.com/en/using-tiktok/exploring-videos/how-tiktok-recommends-content)

**Source type:** `other` (official platform documentation)

---

Official TikTok description of its recommender systems. Content is personalized based on three factor categories: user interactions (likes, shares, watch time — weighted most heavily), content information (sounds, hashtags, views), and user information (device, language, location). The system uses collaborative filtering — "if User A likes videos 1,2,3 and User B likes 1,2,3,4,5, the system may predict User A will also like 4 and 5." TikTok explicitly states it diversifies recommendations to help users discover new interests, and applies safety standards to limit certain content categories in the For You feed.
