# LLaTTE: Scaling Laws for Multi-Stage Sequence Modeling in Large-Scale Ads Recommendation

**Source:** arXiv (LLM-Style Latent Transformers for Temporal Events)
**URL:** https://arxiv.org/html/2601.20083v1
**Date:** January 2026

## Summary (fetched)

Establishes that recommendation sequence models follow predictable power-law
scaling similar to LLMs. Key findings: semantic features are a prerequisite for
scaling (bend the scaling curve); model width must be sufficient before depth
scaling becomes effective; upstream improvements transfer to downstream ranking
(~50% transfer ratio). Production deployment at Meta: 4.3% conversion uplift on
Facebook Feed and Reels using a two-stage architecture with a 45x larger
upstream user model. Deployed as Meta's largest user model.
